# Final Consolidated Research Limitations & Threats to Validity

**Project:** An Integrated Dual-Camera Framework for Context-Aware Motorcycle Helmet Violation Detection with Confidence-Aware Temporal Verification  
**Repository:** `Dual-Camera-Helmet-Violation-Detection` (`main`)

No claim in this repository or its manuscript exceeds the boundaries below. Every limitation is directly measured from saved audit manifests, frozen release tables, or live execution outputs.

---

## 1. Ground Truth Provenance & Circularity Boundaries

1. **AI-Assisted Reference (`AI_ASSISTED_AUDITED`, `human_verified = false`):** All accepted dual-camera evaluation metrics use [`dual_camera_gt_v1.0_ai_assisted_audited`](file:///Users/sayemuddin/Desktop/research_helmet/data/dual_camera_test_v1/releases/dual_camera_gt_v1.0_ai_assisted_audited/README.md), whose initial detections and event boundaries came from Phase 12D/12E pipelines before `86` AI-assisted audit edits (`annotation_corrections.csv`). Stage J bit-reproduces Pass 1, making coupled observation-level F1 (`1.000`, `6,727` / `6,759`) and head-based IDF1 (`0.9987`) **consistency checks by construction**, with degenerate `[1.0, 1.0]` bootstrap CIs ([`INTEGRATED_SYSTEM_RESEARCH_LIMITATIONS.md`](file:///Users/sayemuddin/Desktop/research_helmet/docs/phase12/INTEGRATED_SYSTEM_RESEARCH_LIMITATIONS.md)).
2. **Blind Human Review Halted (`0 / 92` Completed):** Per Principal Investigator directive, the [`dual_camera_gt_v1.1_blind_human`](file:///Users/sayemuddin/Desktop/research_helmet/data/dual_camera_test_v1/releases/dual_camera_gt_v1.1_blind_human/release_metadata.json) blind annotation workqueue remains `PENDING_HUMAN_REVIEW` (`executed_human_units: 0`, `0 / 1,564` response cells filled). Inter-rater reliability (target Cohen's $\kappa \ge 0.85$ / $0.90$) is **unmeasured**.
3. **v1.0 Residual Frame Errors & Non-Coupled Share:** Pass 3 disjoint visual sampling (`168` frames) measured a `39.3%` (`66/168`) blended frame error rate (`46/66` subtrack bounding-box placement only; `11.9%` detection/track-layer error). Stage B full-coverage auditing showed `50.6%` non-coupled subtrack rows (`46.0%` propagated stale Kalman boxes, `4.6%` off-frame), leaving `7,522 / 14,249` rows flagged `spatial_use_valid = false` (including all `760` rows of `pair_002`). Five `pair_004` donning-transition observations are explicitly `occluded_unknown`, and `178` uncertainty rows remain in `annotation_uncertainty.csv`.
4. **High Single-View & Unresolved Event Fraction in `v1.0`:** Out of `70` global physical passes in `v1.0`, `24` (`34.3%`) are labeled `INSUFFICIENT_VISUAL_EVIDENCE` (`29` front-only, `27` back-only, only **`10 / 70` (`14.3%`)** `LINKED_BOTH_VIEWS`, `4` ambiguous). Statistical power on dual-linked physical passes alone is therefore inherently bounded ($n = 10$ linked passes).
5. **v1.0 Pre-GAP-C Event Bias Under Strict Schema Comparison:** When re-evaluating `GAP-C` (`A4`) against `v1.0` strict schema (`N=70`), strict F1 drops from `0.8182` (`A0_DUAL_LEGACY`, `63/70` TP) to `0.6494` (`A4_DUAL_LEGACY`, `50/70` TP; McNemar `p = 0.00098`) because `A4` recovers previously dropped back-camera pillions (shifting e.g. `pair_003`, `013`, `018`, `020`, `021`, `022`, `024` from `DRIVER_NO_HELMET` to `BOTH_NO_HELMET`) and updates role consensus (`pair_010`, `012`, `016`) relative to `v1.0` labels originally anchored to `A0`. Only independent blind human annotation (`v1.1`) can adjudicate which prediction is physically right on those passes.

## 2. Perception, Association & Appearance Limitations

6. **Severe Rear-View Detector Precision Deficit:** On frozen Stage K head detection, front-camera precision is `0.8610` (`AP50 = 0.8932`), whereas back-camera precision falls to **`0.3464` (`AP50 = 0.3467`, `2,138` FP, `3,024` pooled uncoupled boxes)**; Phase 12D back-view smoke tests frequently exhibited weak motorcycle/helmet recall on receding rear-view heads.
7. **Uncalibrated Opposing-View Cue C Discrimination:** Under `TASK-10` real-video verification, coarse HSV+achromatic histograms achieved near-exact resolution invariance (`mean 720p vs 4K self-similarity = 0.9971`) and raised descriptor availability from `6/75` (`8.0%`) to `100.0%` (`55/55` in `C2/C3`). However, positive vs. negative opposing-view pair scores overlapped substantially (`positive mean 0.7223` [$n=5$] vs. `negative mean 0.6641` [$n=20$]), nudging `pair_005` in 4K (`C3`) from `0.6192` (`UNMATCHED`) to `0.6203` — `+0.0003` over the `0.62` association threshold into a false `LINKED`.
8. **Heavy Association Abstention & Tiny-n Subgroup:** Motorcycle association abstains on `38.8%` (`33/85`) of units and orphan association abstains on `63.3%` (`76/120`), while Stage K orphan `F1 = 1.000` rests on **`n = 1` linked orphan pair**.
9. **Heuristic Belief Fusion Weights:** [`FusionConfig`](file:///Users/sayemuddin/Desktop/research_helmet/src/fusion/evidence_fusion.py) priors ($\alpha_0 = 1.0$, $\gamma_F=1.10$, $\gamma_B=0.95$, $K_{\text{conflict}}=0.35$, $P_{\text{viol}}=0.58$) are principled engineering parameters, not learned parameters fit via human cross-validation. Moreover, conservative abstention intentionally lowers binary violation recall on raw fused arms (`0.7250` on `A4_DUAL_FUSED` vs. `0.8250` on `A4_DUAL_FUSED_SPLIT`, where conflict `K=0.35` on `pair_015` converts an uncertain false link into abstention).

## 3. Synchronization, Scope & Compute Boundaries

10. **No Physical Genlock & Uncompensated Clock Drift (`GAP-1`):** Consumer handheld cameras lack genlock and rolling-shutter exposure synchronization (`exposure_sync_model = "container_pts_alignment_not_physical_exposure_genlock"`). Four pairs carry non-trivial clock drift (`pair_004: +36 ms`, `pair_005: +70 ms`, `pair_008: -76 ms`, `pair_015: +74 ms`), making `epsilon_sync_ms` a lower bound up to `114 ms` on `pair_008`.
11. **Monocular Handheld Extrinsics Missing (Cue D Disabled):** Because roadside handheld pairs lack homography or baseline extrinsic calibration, lane/spatial context (`Cue D`) remains disabled by default (`enabled: false`).
12. **License Plate ALPR Out of Evaluation Scope (`0 / 70`):** While [`EasyOCRAdapter`](file:///Users/sayemuddin/Desktop/research_helmet/src/models/ocr_adapter.py#L49) and [`plate_detector_adapter.py`](file:///Users/sayemuddin/Desktop/research_helmet/src/models/plate_detector_adapter.py) exist in-tree, **zero** dual-camera events have assessed license plates (`70 / 70` `NOT_ASSESSED`), precluding any end-to-end citation-issuance validation.
13. **Omitted Metric Families:** Per-frame motorcycle detection AP, person detection AP, standard multi-class `HOTA`, and item-level Stage J rider association cannot be computed from frozen `v1.0` schemas without fabrication.
14. **Compute & Environment Boundaries:** Local verification ran on Apple Silicon macOS (`M1`, CPU / `MPS`), intentionally excluding Kaggle GPU retraining and Stage J 50-stream full-video inference regeneration. The local `.venv` virtualenv is broken (`No module named 'torch.torch_version'`), requiring Python 3.11 (`/opt/homebrew/opt/python@3.11/bin/python3.11`) as documented in [`docs/REPRODUCIBILITY_GUIDE.md`](file:///Users/sayemuddin/Desktop/research_helmet/docs/REPRODUCIBILITY_GUIDE.md).

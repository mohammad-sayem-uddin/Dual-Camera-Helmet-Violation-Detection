    2. 
                
  2. Watch Within Transit Hints: When a workqueue item specifies front_transit_ref_sec_hint or back_transit_ref_sec_hint, annotate that specific motorcycle transit.
    3. 
                
  3. Schema Mapping: Dashboard helmet choices UNCERTAIN and NOT_VISIBLE map deterministically to v1.1 schema occluded_unknown, while preserving exact distinction in JSON.
    4. 
                
  4. Point Events: Fast transits visible cleanly in a single frame may use [t, t] (start == end).
    5. 
                
  5. Non-Motorcycle Transits: If a queued window tracks a bicycle, pedestrian, or false orphan fragment, check Not a Motorcycle Transit and document it in notes.
